FEMTO-RUL · live demo of the deployed API

Bearing degradation monitor

A causal, self-calibrating detector decides when a bearing starts to degrade; only from that point a quantile regression estimates the remaining useful life (RUL). Pick one of the 11 official test bearings of the IEEE PHM 2012 challenge: the service replays its full recording with the same code that serves /predict, one snapshot every 10 seconds, using only past data.

  • The detector learns each bearing's own healthy level, so it needs about 285 snapshots (~47 min) before it can say anything.
  • On the degradation curve, the RUL model beats a countdown baseline on all 9 test bearings where the alarm fires, but its typical error is still about 75% of the remaining life. It is deliberately conservative: early more often than late.
  • No parameter of the detector or of the RUL model was tuned on these 11 bearings.
